# Elementum – Creative Studio Landing Page

A responsive landing page for a creative studio built using React, Vite, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run locally:
   ```bash
   npm run dev
   ```
3. Run with Docker:
   ```bash
   docker-compose up --build -d
   ```

## Features
- Fully responsive design for mobile and desktop
- Scroll-based animations (triggered on every view)
- Sticky navigation with backdrop blur
- Docker configuration for production deployment
- custom SVG branding and icons
